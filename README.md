# Windows Evidence Triage & Anti-Forensics Analyzer

A Python-based Digital Forensics and Incident Response (DFIR) toolkit that automates Windows evidence triage by collecting, analyzing, and correlating forensic artifacts to identify potential anti-forensic activity.

## Features

- Event Log Analysis
- Timestamp Anomaly Detection
- Alternate Data Stream (ADS) Detection
- USB Device History Analysis
- Prefetch Analysis
- Browser Artifact Analysis
- Recycle Bin Analysis
- Registry Analysis
- Timeline Correlation
- Risk Scoring
- HTML/JSON Report Generation

## Objectives

- Reduce manual forensic analysis
- Identify suspicious anti-forensic behavior
- Correlate multiple Windows artifacts
- Generate investigator-ready reports
